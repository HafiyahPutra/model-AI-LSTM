# Bitcoin Price Prediction API (LSTM)

API sederhana untuk memprediksi harga Bitcoin menggunakan model LSTM (Long Short-Term Memory) berdasarkan data real-time dari CoinGecko.

## Endpoint

- `/predict` – Mengembalikan prediksi harga Bitcoin berikutnya (dalam USD)

## Cara Deploy ke Railway

1. Upload repo ke GitHub
2. Login ke [Railway](https://railway.app)
3. Klik "New Project" → "Deploy from GitHub Repo"
4. Pilih repo ini dan deploy 🚀

## Dibuat dengan
- FastAPI
- TensorFlow + Keras
- CoinGecko API
